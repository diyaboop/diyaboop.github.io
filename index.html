What Aggregate Accuracy Hides

End-to-end responsible AI audit pipeline applied to a CIFAR-10 image classifier — surfacing systematic class bias, robustness failures under real-world conditions, and confidence calibration issues that aggregate accuracy metrics hide.

  • Calibration: 54% of predictions over 90% confidence — model is systematically overconfident

Project — 07
SpayTrack India

Full-stack civic tech platform for India's stray animal welfare ecosystem — GPS radar registry, transparent shelter fundraising ledger, and vet operations console for Animal Birth Control tracking.

React 18TypeScriptNode.jsCivic TechResponsible AI
Community Stray Animal Spaying Registry & Shelter Fund Platform

SpayTrack closes the data gap in India's Animal Birth Control program — where millions of sterilizations go untracked and shelter funding remains opaque. Volunteers GPS-tag strays in seconds, shelters publish live fundraising targets, and vets close the loop by signing off on completed surgeries. Built with a hybrid resilient backend that works across low-connectivity environments where India's rescue networks actually operate.

  • GPS Radar Registry: Custom Mercator viewport with color-coded pins (🟢 Spayed / 🔴 Unspayed / 🟡 Unknown) across Delhi, Bangalore, Mumbai, Kolkata, and Pune
  • Care Ledger: Transparent fundraising dashboard per shelter (Friendicoes, CUPA, IDA India) with simulated UPI / Google Pay / card flows
  • Stray Reporter: Multi-step form with auto GPS detection, photo upload, breed tagging, and contact logging — mobile-first
  • Vet Console: Authenticated portal for veterinarians to sign off on surgeries and redeem care funds against verified procedures
  • Hybrid Backend: Express + Vercel serverless with LocalStorage caching engine — offline-resilient, syncs on reconnect
